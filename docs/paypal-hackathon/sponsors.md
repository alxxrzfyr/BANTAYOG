# PayPal AI Hackathon 2026: sponsors

Verified on 2026-11-11 against each sponsor page at
`https://paypalaihackathon.devpost.com/details/<sponsor>`.

A project qualifies for a sponsor prize if it uses "any [Sponsor] tools" (Rules §8). Select the
tool on the submission form. A project can win one sponsor prize only, plus one Grand Prize or
one Honorable Mention. The FAQ says you are "considered for the sponsor prize of each tool you
use".

## Fit for BANTAYOG

- **Render.** The API already deploys on Render. No primary source confirms that a deployment
  alone counts as "use". Ask on the PayPal Discord before you rely on it.
- **AG Grid.** The admin portal has tables. A prize needs custom widgets or theming, not a
  default grid.
- **Channel3.** A product search API. The prize needs a live call inside the product flow.

Sponsor credits come from sponsor companies, not from PayPal or Devpost. The "financial or
preferential support" clause in §4 names only PayPal and Devpost. Devpost has not confirmed that
sponsor credits are outside that clause.
