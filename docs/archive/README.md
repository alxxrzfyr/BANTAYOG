## Archive rules

- Check the implementation before archiving a completed plan. A closed checklist alone is not proof.
- Keep unfinished features, open security reviews, and their acceptance conditions active.
- Keep ADRs and current API, schema, setup, and security contracts in their normal locations.
- Update incoming links and add a status note when moving a document.
- Historical paths and results in snapshots are not current setup instructions.
- An archive is still part of the repository. It does not hide private data or remove Git history.
- Never put secrets, credentials, private reports, or personal execution notes here.
